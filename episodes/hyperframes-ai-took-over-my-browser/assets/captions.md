## LinkedIn

Most AI assistants I've tested can talk about a task. Very few can actually go do it inside a
real browser.

Playwright MCP changes that. It's an open source Model Context Protocol server from Microsoft
that gives an AI agent real control of a browser, not a simulated one.

The mechanism is straightforward but genuinely useful. You describe a task in plain English.
The agent opens Chrome, reads the live page content, locates the right element, fills in
whatever forms are required, submits, and scrolls to confirm the result actually happened. No
hardcoded selectors, no pre-scripted click paths.

I ran it against a real signup flow to see how it handled a multi-step form with a login gate
partway through. It read each screen, made the right call on what to do next, and finished the
task without any manual intervention.

For anyone evaluating agent tooling right now, this is a useful data point on how close
browser-level automation has gotten to actually working unattended.
