## Line 1: Hook (Frame 1)

    If you're building with AI, you've probably noticed something. It does the work faster than you ever could. So here's the real question: what's actually left for you to be good at?

## Line 2: Verification (Frame 2)

    It can sound completely confident about something that's totally wrong. It doesn't know true from convincing. That part's still on you.

## Line 3: Taste (Frame 3)

    It can pass every check you give it, and the result can still feel empty. Passing a test and being good were never the same thing.

## Line 4: Voice (Frame 4)

    It can write something with nothing wrong in it, and it still won't sound like you. Correct was never the same as yours.

## Line 5: Close + invitation (Frame 5)

    So the skill that actually matters now isn't speed. It's judgment: knowing what's real, what's good, and what's actually you. Follow along, I'm figuring this out in real time too.
