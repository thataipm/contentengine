## LinkedIn

A small fix for a problem every Claude Code user has run into: one agent trying to do
everything in a single conversation until the context window is a junk drawer.

cavecrew splits that single agent into three specialized roles. An investigator that only
locates the problem (returns file and line, nothing else). A builder that only makes
scoped, one or two file changes, and refuses the task outright if it's bigger than that. A
reviewer that only reviews and flags issues by severity, with no write access to the code
at all.

The activation is just plain language, not a slash command. You tell Claude Code to
delegate to a subagent or use cavecrew, and it routes the work to the right role on its own.
