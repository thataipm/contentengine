# ThatAIPM — Content Pillar Pivot (decided 2026-08-09)

Locked after 6 educational "How AI Actually Works" videos didn't get the traction expected.
This is NOT a new channel — everything here posts to the existing **@thataipm** Instagram
channel alongside (eventually reformatted) educational content. See `CLAUDE.md` §1 for the
original channel brief; this doc covers the pivot on top of it.

## Rotation

- **60% — Trending Claude Code skills/plugins.** The new primary pillar, this doc's main
  content. Sourced via continuous research (GitHub stars, community roundups, viral moments),
  not invented topics. Format modeled directly on two reference videos the user supplied and I
  analyzed frame-by-frame (2026-08-09): hook-threat opener → per-tool beat (name, one-line
  value, recreated UI mockup, concrete stat payoff) → "Comment [KEYWORD] and I'll send you the
  link" close. See [[feedback-follow-only-cta-until-followers]] memory — comment-gate CTA is
  back for this pillar specifically, reversing the earlier follow-only rule.
- **20% — Educational** ("How AI Actually Works" content: cm1 Tokens, tn1 GPT-3 math, the
  30-episode bank in `how_ai_works_content_plan.md`). Titles/structure to be reformatted later,
  not done yet — don't touch this pillar's existing content plan until the user revisits it.
- **20% — Personal AI takes.** Opinion content drafted from current AI news, written by me
  (Claude) based on what's actually happening in AI at the time, not evergreen. No bank of
  pre-written ideas here — these get sourced fresh, closer to when each one is actually made.

## Pillar 1 (60%) — locked idea bank, 2026-08-09

All real, sourced 2026-08-09 via web research, not invented. Re-verify stats before using if
much time has passed — this ecosystem moves fast and star counts/rankings shift.

1. **The Karpathy skill** — a single CLAUDE.md file, zero code, hit 144k-220k GitHub stars in
   weeks after Andrej Karpathy (Tesla Autopilot, OpenAI co-founder) publicly ranted about AI
   coding-agent failure patterns and a developer (Forrest Chang) turned it into 4 rules.
   `github.com/forrestchang/andrej-karpathy-skills`

   review) as composable skills, works across Claude Code, Cursor, Codex, Copilot.

4. **Context7** (Upstash) — 39.3k stars, injects real-time up-to-date library docs into prompts
   so Claude stops citing outdated APIs.
5. **Antigravity Awesome Skills** — 22k+ stars, one repo bundling 1,234+ skills.

**Token/cost-saving (matches the two reference videos' own topic directly):**
